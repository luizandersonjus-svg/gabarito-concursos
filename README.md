# Gabarito Concursos

Plataforma de estudos para concursos: painel de desempenho por matéria, tópicos e subtópicos do edital, cronograma personalizado, flashcards com repetição espaçada, caderno de erros, curvas de aprendizado e ranking do grupo.

- Site: publicado pelo GitHub Pages a partir deste repositório (`index.html`).
- Dados e login: Supabase (projeto `plataforma-estudos`). Cada aluno só lê e altera os próprios dados; o resumo do ranking e os baralhos compartilhados são visíveis a todos os alunos logados.
- `supabase.js` é a biblioteca oficial `@supabase/supabase-js` 2.45.4 (build UMD), incluída aqui para não depender de CDN.
